# 볼펜 조립 · 부품 집기 확인 (학생 프로젝트 데모)

기존 QR(주소 `.../desk-ar/`)로 열립니다. 대상: uni 제트스트림 3색 SXE3-400-05.

1. 분해한 부품 5개(볼펜 상단, 볼펜 하단, 검정·빨강·파랑 리필)를 **밝은 단색 책상이나 흰 종이** 위에 서로 떨어뜨려 놓습니다.
2. QR로 페이지를 열고 **시작** → 부품이 모두 보이게 위에서 비춥니다.
3. 부품마다 윤곽과 이름이 자동으로 붙습니다(학습·등록 없음).
4. 안내대로 부품을 집습니다: 볼펜 상단 → 검정 → 빨강 → 파랑 리필 → 볼펜 하단
   - 맞는 부품: 초록 + "맞아요!" + 높은 소리, 다음 부품 안내
   - 틀린 부품: 빨간 테두리 + "틀렸어요! ○○을 집었어요 · 내려놓고 △△을 집으세요" + 낮은 소리 + 진동(Android)
   - 틀린 부품을 다시 내려놓으면 경고가 풀립니다.

## 동작 방식
- 화면에서 가장 많은 색을 바닥색으로 잡고(손이 들어와도 천천히만 바뀜), 바닥에 둘러싸인 어두운·색 있는 덩어리를 부품으로 봅니다. 손은 화면 가장자리에서 이어져 들어오므로 부품이 아닙니다.
- 5개 부품을 서로 비교해서 이름을 정합니다: 가늘고 긴 3개는 리필(빨간 화소가 있는 것=빨강, 파란 화소가 있는 것=파랑, 둘 다 없는 것=검정. 각 리필 끝부분의 색 띠가 가장 강한 단서), 굵은 2개 중 긴 것=상단, 짧은 것=하단.
- 한 번 이름이 붙은 부품은 위치로 따라가므로, 손이 일부를 가려도 이름이 옮겨 가지 않습니다.
- 부품이 사라지고 그 자리에 바닥이 다시 보이면 "집었다"로 판정합니다(손에 가려진 동안은 판정 보류).
- 모든 처리는 휴대폰 안에서만 합니다. 외부 라이브러리 없음.

## 확인한 것
- 사용자 실제 화면(나무 책상 위 5개 부품): 5개 모두 맞게 인식
- 그 사진으로 만든 영상에서 상단 집기(맞음) → 5번째 리필 집기(틀림) → 내려놓기(해제) → 3번째 리필 집기(맞음): 4개 모두 정확
- 손이 부품을 가리는 합성 영상: 4개 사건 정확, 잘못된 판정 0건

## 한계
- 부품이 서로 붙어 있거나 화면 가장자리에 걸치면, 또는 바닥이 어둡거나 무늬가 강하면 인식이 틀릴 수 있습니다.
- 실제 손으로 집는 장면은 실기기에서 확인이 필요합니다.
