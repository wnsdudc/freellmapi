# 볼펜 조립 · 부품 집기 확인 (학생 프로젝트 데모)

기존 QR(주소 `.../desk-ar/`)로 열립니다. 대상: uni 제트스트림 3색 SXE3-400-05. 시연 환경: 밝은 민무늬 책상.

1. 부품 5개(볼펜 상단, 볼펜 하단, 검정·빨강·파랑 리필)를 책상 위에 서로 떨어뜨려 놓습니다.
2. QR로 페이지를 열고 **시작** → 5개가 모두 화면 안에 들어오게 비춥니다 (거치대 권장, 손으로 들어도 됨).
3. **[부품 사진 찍기]**: 0.6초 동안 6장면을 모아 투표로 이름을 정합니다.
4. 확인 화면: 멈춘 사진 위에 이름표가 붙습니다. 틀린 이름은 이름표를 눌러 바꿉니다 (이미 쓰인 이름은 서로 맞바뀜). 5개가 모두 지정되어야 **[시작]**이 눌립니다.
5. 안내대로 부품을 집습니다: 볼펜 상단 → 검정 → 빨강 → 파랑 리필 → 볼펜 하단
   - 맞는 부품: 초록 + "맞아요!" + 높은 소리
   - 틀린 부품: 빨간 테두리 + "틀렸어요! ○○을 집었어요" + 낮은 소리 + 진동(Android). 다시 내려놓으면 풀립니다.

## "집었다" 판정 (오판 방지)
다음이 모두 맞을 때만 집은 것으로 봅니다.
- 부품이 사라질 때 손(화면 가장자리에서 들어온 큰 영역)이 그 자리에 왔다
- 손이 그 자리를 떠났다 (손이 부품 위를 지나가기만 하면 부품이 다시 보이므로 판정 없음)
- 그 자리에 책상 바닥이 보인다 (사진 찍을 때 그 부품 자리의 모습과 비교)
- 그 자리가 화면 안에 있다. 부품이 화면 밖으로 나가면 "부품이 화면 밖에 있어요" 안내만 하고, 다시 들어온 뒤 1초 동안은 판정하지 않음
- 다른 부품은 여전히 보인다 (카메라를 다른 곳으로 돌린 경우 제외)

사진에서 정한 이름은 위치로 따라갑니다. 휴대폰이 움직이면 부품들이 함께 움직인 만큼을 계산해 모든 자리(손에 가려진 부품 포함)를 옮깁니다. 사진 찍을 때 이미 화면 가장자리에 있던 것(책상 모서리 등)은 손으로 보지 않습니다.

## 확인한 것 (자동 시험, 실제 사진의 부품 + 책상 색으로 만든 영상)
- 손이 리필 3개 위를 지나감 → 판정 0건
- 카메라를 옮겨 부품이 화면 밖으로 나갔다 돌아옴 → 판정 0건, 안내 표시
- 이어서 상단 집기(맞음) → 5번째 리필 집기(틀림) → 내려놓기(해제) → 3번째 리필 집기(맞음): 4건 모두 정확
- 거치대(흔들림 없음) 3회, 손으로 든 흔들림 2회, 흰 종이·나무 탁자 장면 1회 모두 정확
- 사진 인식: 5개 모두 이름 지정(0.6초), 이름표 눌러 바꾸기·맞바꾸기 동작

## 한계
- 실제 손과 실기기 카메라로는 확인하지 못했습니다(시험 영상의 손은 합성).
- 손 색이 책상 색과 비슷하면 손을 못 알아봐서, 부품이 1.5초 이상 사라졌을 때 판정합니다(조금 늦음).
- 부품끼리 겹치거나 화면 가장자리에 걸친 채로 사진을 찍으면 인식이 틀릴 수 있습니다 → 확인 화면에서 고치거나 다시 찍기.

모든 처리는 휴대폰 안에서만 합니다(외부 전송 없음). 이전 버전: 책상 AR은 `desk/`, 이전 볼펜 버전은 git 기록.
