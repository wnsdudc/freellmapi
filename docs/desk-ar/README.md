# 3색 볼펜 AR 조립 실습 (학생 프로젝트 데모)

같은 QR 코드(주소 `.../desk-ar/`)로 열립니다. 이전 책상 버전은 [`desk/`](desk/)에 그대로 남아 있습니다.

- 대상: uni 제트스트림 3색 **SXE3-400-05** (리필 **SXR-80-05**). 펜 라벨 사진 기준.
- 부품(인식 대상 7가지): 빈 화면, 완성 볼펜, 그립(앞축), 검정·빨강·파랑 리필, 본체(레버·클립)
- 화면: 한국어 / English 선택. iPhone(Safari), Android(Chrome) 지원

## 사용 순서
1. QR을 찍어 페이지를 열고 언어를 고른 뒤 **카메라 켜고 시작**
2. **부품 등록(시연 전 1회, 2~3분)**: 부품마다 [등록 시작] → 3초 뒤 6초 동안 부품을 상자 안에서 천천히 돌립니다.
   등록 순서(빈 화면 → 완성 볼펜 → 그립 → 검정 → 빨강 → 파랑 → 본체)가 곧 분해 순서입니다.
   등록한 내용은 그 휴대폰 브라우저에만 저장되어, 다시 열어도 유지됩니다.
3. **부품 인식 탭**: 단계마다 "지금 들 부품"이 나옵니다. 부품을 상자에 비추면
   - 맞는 부품: 초록 상자 + "맞는 부품입니다" + 높은 소리
   - 다른 부품: 빨간 상자 + "다른 부품입니다 · ○○입니다 · 지금은 △△이 필요해요" + 낮은 소리 + 진동(Android만)
   - 오른쪽 아래 작은 창에 그 단계의 동작이 3D로 반복됩니다.
4. **AR 보기 탭**: QR을 비추면 QR 위에 3D 볼펜이 나타나 단계를 보여줍니다. QR이 인식되면 **바닥에 놓고 보기**
   (Android: 이 페이지 안에서 바닥 인식, iPhone: AR Quick Look, 4배 확대 모델)

## 조립 단계 (8단계)
부품 확인 → 본체 준비 → 검정 리필 → 빨강 리필 → 파랑 리필 → 그립 조이기 → 작동 확인 → 완성

근거: 三菱鉛筆 공식 FAQ "多色ボールペン/多機能ペンの芯を替えたい"(검색 결과 요약으로 확인, 사이트는 자동 접근 차단)와
제트스트림 4&1 교체 방법 글(connie3.com). 그립을 잡고 본체를 반시계로 돌려 분리 → 바꿀 색 레버를 눌러 리필을 내밀고 앞쪽으로 뽑기
→ 새 리필을 구멍에 꽂기 → 시계 방향으로 조이기 → 다른 레버를 누르면 나와 있던 리필이 들어감.
**리필 스프링 등 내부 부품 유무는 확인하지 못했습니다** [확인 필요]. 실제 분해 시 부품이 더 있으면 추가해야 합니다.

## 인식 방식
- 휴대폰 안에서 MobileNet v1(0.25) 이미지 특징 + 색 특징으로 k-최근접 이웃 분류 (서버 전송 없음)
- 0.6초 동안 같은 결과가 이어질 때만 판정. 잘못된 부품 경고는 더 엄격한 기준(6프레임 중 5, 신뢰도 65%)을 넘어야 울림
- 합성 이미지 시험(가상 부품 3D 렌더): 한 장 기준 정확도 95.7%, 맞는 부품을 들었을 때 잘못 울린 경고 1.4%.
  **실제 펜 인식률은 시연 기기·조명에서 확인 필요**. 완성 볼펜과 본체가 가장 헷갈립니다.

## 파일
| 파일 | 역할 |
|---|---|
| `index.html`, `app.js` | 화면과 전체 흐름 |
| `recognizer.js` | 부품 인식(특징 추출, 분류, 저장, 판정 안정화) |
| `tracker.js`, `detector.js` | QR 추적(AR 보기 탭) |
| `pen.js` | 볼펜 3D 모델(근사 형상)과 조립 단계 |
| `text.js` | 한국어·영어 문구 |
| `usdz/` | iPhone AR Quick Look용 단계별 애니메이션 |
| `tools/` | USDZ 생성기, 합성 이미지 인식 시험 페이지 |
| `vendor/` | three.js r160 (MIT), jsQR 1.4.0 (Apache-2.0), TensorFlow.js 4.22.0 (Apache-2.0), MobileNet v1 0.25 가중치 |

## 주소 옵션
`?lang=en` 영어, `?step=3` 3단계부터, `?tab=ar` AR 보기 탭으로 시작, `?mode=viewer` 카메라 없이 3D, `?skipreg=1` 등록 건너뛰기, `?autostart=1` 시작 화면 없이 카메라 켜기
