# 볼펜 조립 · 부품 집기 확인 (학생 프로젝트 데모)

기존 QR(주소 `.../desk-ar/`)로 열립니다.

1. 분해한 부품 5개(본체, 그립, 검정·빨강·파랑 리필)를 **흰 A4 종이** 위에 서로 떨어뜨려 놓습니다.
2. QR로 페이지를 열고 **시작** → 휴대폰으로 종이 전체가 보이게 위에서 비춥니다.
3. 부품마다 윤곽과 이름이 자동으로 붙습니다(학습·등록 없음).
4. 위쪽 안내대로 부품을 집습니다: 본체 → 검정 → 빨강 → 파랑 리필 → 그립
   - 맞는 부품: 초록 화면 + "맞아요!" + 높은 소리, 다음 부품 안내
   - 틀린 부품: 빨간 테두리 + "틀렸어요! ○○을 집었어요 · 내려놓고 △△을 집으세요" + 낮은 소리 + 진동(Android)
   - 틀린 부품을 종이에 다시 내려놓으면 경고가 풀립니다.

## 동작 방식
- 종이(가장 큰 흰 영역) 안에 있는 어두운·색 있는 덩어리를 부품으로 봅니다. 손은 종이 바깥에서 이어져 들어오므로 부품으로 세지 않습니다.
- A4 크기(297×210 mm)로 실제 길이를 계산해, 가는 것은 리필(색으로 검정·빨강·파랑), 굵은 것은 길이로 본체(약 66–118 mm)·그립(약 28–66 mm)으로 구분합니다.
- 부품이 사라지고 그 자리에 흰 종이가 다시 보이면 "집었다"로 판정합니다. 손에 가려져 안 보이는 동안에는 판정하지 않습니다.
- 모든 처리는 휴대폰 안에서만 합니다. 외부 라이브러리 없음.

## 한계
- 흰 종이가 아니거나, 부품이 서로 붙어 있거나, 종이 가장자리에 걸치면 인식이 틀릴 수 있습니다.
- 크기 기준값은 실측이 아닌 추정치입니다(본체 약 92 mm, 그립 약 52 mm, 리필 약 96 mm로 가정). **실제 펜 사진으로 확인이 필요합니다.**
- 시험은 합성 영상으로만 했습니다(손으로 본체 집기 → 빨강 잘못 집기 → 내려놓기 → 검정 집기: 4개 사건 모두 정확, 지연 약 0.2–0.4초).
