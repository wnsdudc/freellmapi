# 교실 책상 AR 조립 안내 (학생 프로젝트 데모)

QR 코드를 휴대폰으로 찍으면 이 페이지가 열리고 카메라가 켜집니다.

1. **QR 위에서 보기:** 같은 QR 코드를 비추면 QR 위에 3D 책상이 나타나 조립 순서를 10단계로 보여줍니다.
2. **바닥에 놓고 보기:** QR이 한 번 인식되면 버튼이 나타납니다. 휴대폰의 AR 기능으로 아무 바닥에나 실제 크기 책상을 놓고 단계를 볼 수 있습니다.
   - Android(Chrome, ARCore 지원 기종): 이 페이지 안에서 바닥 인식(WebXR). 이동·회전·크기 버튼과 단계 카드가 그대로 보입니다.
   - iPhone(Safari): 아이폰 내장 AR 화면(AR Quick Look)이 열리고, 단계별 애니메이션 파일(`usdz/`)이 바닥에 놓입니다.

- 주소: https://wnsdudc.github.io/freellmapi/desk-ar/
- 제품은 가상의 데모 제품(DEMO-DESK-01, 65×45×72 cm)이며 실제 제조사의 설명서가 아닙니다.

## 흔들림 보정 (QR 위에서 보기)
- QR을 찾은 뒤에는 그 주변만 원본 해상도(최대 3배 확대)로 다시 찾아 모서리 위치를 더 정밀하게 얻습니다.
- 모서리 좌표에 One Euro 필터를 적용해, 가만히 있을 때의 떨림은 강하게 줄이고 움직일 때는 바로 따라가게 했습니다.
- 손떨림 모의 영상 기준: 책상 윗면 흔들림 13 px → 약 3–4 px, 한 프레임 최대 튐 25 px → 약 3.5 px, 움직일 때 지연 약 7 px 이내.

## 파일
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 |
| `app.js` | 카메라, QR 추적·보정, 바닥 AR(WebXR, Quick Look), 단계 진행 |
| `detector.js` | 카메라 프레임에서 QR 네 모서리를 찾는 워커 (jsQR) |
| `desk.js` | 책상 3D 모델과 조립 단계 |
| `text.js` | 화면 문구 (한국어·영어) |
| `usdz/` | iPhone AR Quick Look용 단계별 애니메이션 파일 (실제 크기) |
| `tools/` | `usdz/` 파일을 다시 만드는 생성기 (`tools/gen-usdz.html`) |
| `vendor/` | three.js r160 (MIT), jsQR 1.4.0 (Apache-2.0) |

## 주소 옵션
- `?lang=en` 영어 화면, `?step=5` 5단계부터 시작, `?mode=viewer` 카메라 없이 3D 보기
- `?focal=0.75` 카메라 화각 고정(기본은 QR 모양으로 자동 추정), `?filter=0` 흔들림 보정 끄기(비교용)
